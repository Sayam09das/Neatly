# Conversion Landing Page Architecture Skill — Neatly

This skill provides guidelines for conversion-oriented section ordering, lead flow hierarchy, and landing page UX in **Neatly**.

---

## 1. Landing Page Section Flow

The homepage MUST follow this exact conversion-tested 13-section sequence:

```text
1. Sticky Navbar          -> Branding, Navigation, Contact Phone, "Get a Quote" CTA
2. Hero Section           -> Value Prop, Headline, Primary CTA, Secondary Link, Trust Badges
3. Trust Indicators Bar   -> Insurance, Guarantee, Vetting, Rating Badges
4. Why Neatly             -> Core Differentiators (Eco-friendly, Vetted, Guaranteed, Transparent)
5. Services Overview      -> Package cards with clear scope links
6. Featured Work Showcase -> Interactive Before/After slider
7. How It Works           -> 3-step simple booking process
8. Statistics Bar         -> Social proof metrics (500+ Cleaned, 99.4% Satisfaction)
9. Testimonials Showcase  -> Verified customer reviews
10. Primary CTA Banner    -> Final high-impact conversion push to /quote
11. Blog Highlights       -> SEO authority articles
12. Newsletter Capture    -> Minimal top-of-funnel email subscribe form
13. Footer Architecture   -> Business address, hours, nav, legal links, copyright
```

---

## 2. Conversion Rules

1. **Lead Generation Focus:** Every section must guide the user toward requesting a custom quote.
2. **Low Friction:** Keep CTAs consistent in wording ("Request a Free Quote" or "Get a Quote") pointing to `/quote`.
3. **Proof Proximity:** Always position trust signals and social proof adjacent to primary conversion triggers.
