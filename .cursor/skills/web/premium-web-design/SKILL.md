# Premium Web Design Master Skill — Neatly

This master skill provides architectural and creative guidance for building high-trust, premium marketing web experiences for **Neatly**.

---

## 1. Aesthetic Identity

Neatly is engineered to project the visual quality and authority of an award-winning modern product website while remaining completely tailored to a high-end professional cleaning business:

> **Clean, Minimal, High-Trust, Premium, Calm, Modern, Professional.**

---

## 2. Key Structural Patterns

### 2.1 Hero Section
* High-impact editorial headline, clear value proposition copy, primary "Request a Free Quote" CTA, secondary service link, trust badges, and warm high-definition photography showcasing an immaculate space.

### 2.2 Credibility & Trust Bar
* Positioned directly beneath the Hero. Features 4 key trust pillars: Licensed & Insured, 100% Reclean Guarantee, Vetted Professionals, 4.9/5 Star Rated.

### 2.3 Interactive Work Showcase
* Interactive Before/After image comparison slider allowing prospects to visually inspect real cleaning results.

### 2.4 Transparent Scope & Service Grid
* Grid of core cleaning packages (Residential, Deep Clean, Move-In/Out, Commercial) with explicit checklists detailing standard inclusions.

### 2.5 Process Clarity (How It Works)
* 3-step timeline (1. Request Quote -> 2. Confirm Schedule -> 3. Enjoy Clean Space) eliminating process ambiguity.

### 2.6 Authentic Customer Advocacy
* Verified customer reviews with star ratings, locations, and clean testimonial cards.

### 2.7 Final Conversion Banner & Footer
* Prominent full-width conversion banner driving visitors directly into `/quote`, followed by an organized, accessible footer.
